## 🛠️ Android 手機安裝指引

由於此安裝檔是直接從伺服器下載（未透過 Google Play），安裝時請依循以下步驟：

1. **點擊上方連結下載 APK 檔案**。
2. 下載完成後，點擊通知欄或「下載」資料夾中的 APK 檔案進行安裝。
3. 若系統彈出 **「已封鎖安裝未知來源應用程式」** 的安全防護提示：
   - 點選畫面上的 **「設定」**。
   - 開啟 **「允許來自此來源的應用程式」**（或「允許安裝不明應用程式」）。
   - 返回安裝畫面，點擊 **「安裝」** 即可順利完成。
4. 安裝完成後開啟 App：
   - **學生與家長**：輸入機構發放之「專屬邀請碼」即可直接使用。
   - **司機與管理人員**：輸入企業編號及帳號密碼登入執勤。
